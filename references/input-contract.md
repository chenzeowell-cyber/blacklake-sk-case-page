# 输入合约

## 每次必须提供

| 字段 | 内容 | 建议长度 |
|---|---|---:|
| `client_name` | 客户名称 | 2–12 字 |
| `headline` | 客户名称＋主要产品/业务 | 8–12 字 |
| `subtitle_clauses` | 三个成果或价值短语 | 每项 4–12 字，连同顿号合计不超过 27 字 |
| `profile` | 成立时间、主营业务、市场或客户类型 | 60–100 字 |
| `pains` | 恰好 3 项：标题＋事实说明 | 标题 6–16 字；正文 45–78 字 |
| `values` | 恰好 3 项：标题＋功能动作＋业务价＋截图 | 标题 6–16 字；正文 45–60 字 |
| `media.scene_image` | 客户产品、工厂或行业场景 | 3:1 至 16:9 |
| `media.result_image` | 数据看板、管理场景或成果场景 | 3:1 至 16:9 |

`sources` 用于记录访谈、Word、新闻稿、网页或内部备注等事实依据。正式客户案例建议至少一项。

## 图片标记

每张可被误认为真实客户环境或真实产品的图片都支持：

```json
{
  "path": "media/factory.jpg",
  "ai_generated": true,
  "caption": "行业场景示意"
}
```

`ai_generated: true` 时，模板自动显示“AI 示意图”。真实客户照片和真实产品截图设为 `false`。

## 推荐收集提示

```text
请提供：
1. 客户名称、行业和主要产品；
2. 60–100 字客户简介；
3. 三个业务痛点，以及各自对应的解决方式和价值；
4. 三张可对应价值点的黑湖小工单真实截图；
5. 一张客户产品/工厂图和一张数据/管理场景图；
6. 资料来源、需隐藏的信息，以及是否允许使用 AI 示意图补足场景。
```

复制 [`case-template.json`](case-template.json)，用本次内容替换占位值。
